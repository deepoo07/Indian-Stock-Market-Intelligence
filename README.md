# Indian Stock Market Intelligence Dashboard

## Project Overview

The **Indian Stock Market Intelligence Dashboard** is an interactive Power BI project designed to analyse historical stock market data for selected companies listed on the National Stock Exchange (NSE) of India.

The dashboard provides insights into stock price trends, trading activity, daily returns and market volatility, helping users explore historical market behaviour through interactive visualizations.

## Companies Analysed

- Reliance Industries Limited
- Tata Consultancy Services (TCS)
- State Bank of India (SBI)
- Infosys
- HDFC Bank
- ICICI Bank
- ITC

## Dashboard Features

- Average closing price
- Average daily trading volume
- Total trading volume
- Highest and lowest closing prices
- Average daily return
- Annualized volatility
- Historical closing price trends
- Daily return analysis
- Monthly trading volume and return analysis
- Comparative average closing prices across stocks
- Interactive stock selection and date filtering

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Python
- Yahoo Finance (`yfinance`)
- Microsoft Excel / CSV

## Data

Historical stock market data was collected using Python and the `yfinance` library.

The dataset includes historical price and trading volume information for the selected NSE-listed companies.
